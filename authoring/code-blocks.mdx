Mintlify uses [Shiki](https://shiki.matsu.io) for syntax highlighting. Every code block is automatically styled to match your docs theme in both light and dark mode — no custom CSS, no configuration, no extra dependencies. You focus on the code; Mintlify handles the presentation.

<Warning>
  Never wrap code blocks in styled `div` elements or add manual background colors. Doing so overrides Shiki's theming and breaks consistency across light and dark mode.
</Warning>

## Basic code blocks

Wrap your code in triple backticks and add a language identifier immediately after the opening fence. Mintlify uses the language tag to apply the correct syntax grammar.

**JavaScript**

```js
async function fetchUser(userId) {
  const response = await fetch(`/api/users/${userId}`);
  return response.json();
}
```

**Python**

```python
def fetch_user(user_id: str) -> dict:
    response = requests.get(f"/api/users/{user_id}")
    response.raise_for_status()
    return response.json()
```

**Shell**

```bash
curl -X GET https://api.example.com/users/123 \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json"
```

Mintlify supports all [languages recognized by Shiki](https://shiki.matsu.io/languages). Use the short alias (`js`, `ts`, `py`, `sh`, `bash`, `yaml`, `json`, `mdx`, etc.) for best results.

## Code block options

You can enrich any code block with additional options by adding them as a space-separated list after the language tag on the opening fence.

**Title / filename** — add a `title` attribute to label the block with a filename or descriptive heading. Write it as `title="your-filename.ext"` directly after the language identifier:

```
```ts title="lib/api.ts"
export async function getUser(id: string) {
  return fetch(`/api/users/${id}`).then(r => r.json());
}
```
```

```ts title="lib/api.ts"
export async function getUser(id: string) {
  return fetch(`/api/users/${id}`).then(r => r.json());
}
```

**Line numbers** — add `lines` after the language tag to render line numbers in the left gutter:

```
```python lines
import os

def main():
    key = os.getenv("API_KEY")
    print(f"Using key: {key}")
```
```

**Highlight** — use `{n}` or `{n-m}` after the language tag to highlight specific line numbers with a background color:

```
```js {3-5}
function setup(config) {
  const client = new Client();
  client.baseURL = config.url;
  client.timeout = config.timeout;
  client.retries = config.retries;
  return client;
}
```
```

**Focus** — use `focus={n}` to dim every line except the one you want to draw attention to:

```
```ts focus={4}
const client = new MintlifyClient({
  apiKey: process.env.MINTLIFY_KEY,
  project: "my-docs",
  theme: "dark",   // <-- this line is in focus
});
```
```

**Wrap** — add `wrap` to prevent horizontal scrolling by soft-wrapping long lines:

```
```bash wrap
curl -X POST https://api.example.com/v1/documents/generate \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"template":"onboarding","user_id":"u_123"}'
```
```

**Expandable** — add `expandable` to collapse a long code block behind a "show more" toggle, keeping the page compact until the reader needs the full content:

```
```json expandable
{
  "id": "doc_abc123",
  "title": "Onboarding Guide",
  "created_at": "2024-01-15T10:30:00Z",
  "status": "published"
}
```
```

```json expandable

## Diff markers

Highlight added and removed lines within a code block using Shiki's inline comment markers. This is ideal for migration guides and changelog entries that show what changed.

Use `// [!code ++]` at the end of a line to mark it as added, and `// [!code --]` to mark it as removed:

```js title="Before and after"
function connect(options) {
  const client = new Client(options.host); // [!code --]
  const client = new Client(options.url); // [!code ++]
  client.authenticate(options.apiKey); // [!code --]
  client.authenticate(options.token); // [!code ++]
  return client;
}
```

Place the marker comment at the end of the line you want to annotate. Mintlify renders `--` lines with a red background and `++` lines with a green background, both calibrated for readability in light and dark mode. The marker comment itself is hidden in the rendered output.

## CodeGroup for multiple languages

Wrap multiple code blocks in a `<CodeGroup>` to display them as a tabbed group. This is the recommended pattern for showing the same operation in several languages or runtimes.

<CodeGroup>

```ts title="TypeScript"
import { MintlifyClient } from "@mintlify/sdk";

const client = new MintlifyClient({ apiKey: process.env.API_KEY });
const page = await client.pages.get("quickstart");
console.log(page.title);
```

```python title="Python"
from mintlify import MintlifyClient

client = MintlifyClient(api_key=os.environ["API_KEY"])
page = client.pages.get("quickstart")
print(page.title)
```

```bash title="cURL"
curl https://api.mintlify.com/v1/pages/quickstart \
  -H "Authorization: Bearer $API_KEY"
```

</CodeGroup>

To create a `CodeGroup`, open with a `<CodeGroup>` tag, place your code blocks one after the other (each with a `title` attribute), then close with `</CodeGroup>`. Each code block becomes one selectable tab.

<Note>
  Every code block inside a `<CodeGroup>` must have a `title` attribute. The title becomes the tab label. Blocks without a title will render without a selectable tab.
</Note>
